Análisis Frontend‑Design de "Entrena Tu Ser"

Concepto de Diseño (1–3 oraciones)

El proyecto presenta una identidad visual basada en texturas de papel marmoleado (Ebru) con acentos naranja y verde agua. Sin embargo, el diseño actual choca con varios principios del framework frontend‑design: usa fuentes del sistema genéricas, una paleta de color que no sigue una coherencia intencional y componentes de interfaz que carecen de jerarquía visual definida. El reto es dotar a la app fitness de una dirección estética memorable, producción‑grade y coherente con el vital balance (#ff6b35, #2dd4bf) sin caer en patrones SaaS genéricos.

✔️ Qué Funciona Bien

  • El uso de una cuadrícula base (grid) en las pantallas de dashboard brinda ritmo y predictibilidad al usuario.
  • Los estados :focus-visible están presentes, lo cual es un buen punto de partida para accesibilidad.
  • La estructura de 6 pantallas (Login, Register, Progress, Workout, Map, Profile) cubre el flujo principal de una app fitness.
  • Las dimensiones móviles (375px × 812px) indican que el diseño nació pensando en experiencia real de dispositivo.

🚨 Áreas Críticas de Mejora

  • Paleta de color: Reemplazar --ebru-orange #8da399 (verde oliva) por naranja vital #ff6b35 consistente en toda la UI.
  • Tipografía: Comprometerse con Syne (headings) + DM Sans (cuerpo); remover Playfair Display a menos que sea override controlado.
  • Details visuales: Añadir texturas de grain, shadows más definidos, borders accentuados con color vital, background treatments que no sean solid-color aburridos.
  • Avoid SaaS: Definir una dirección (Bolder para onquierking, Quieter para workspace, Distill para docs) y comprometerse totalmente.
  • Jerarquía visual: Los headings deben usar Syne con peso 700-800; body text DM Sans a 16px mínimo con line-height generoso.

💡 Acciones Recomendadas (Seguir Framework Impeccable)

  1. Definir una dirección estética: Elegir BOLDER (marketing/onboarding), QUIETER (workspace/dashboards) o DISTILL (docs/tutorials). No mezclar estilos conflictivos.
  2. Commit a la tipografía: Syne 800 para títulos, DM Sans regular/medium para cuerpo. Evitar system fonts (Arial, Roboto, Inter "defaults").
  3. Unificar la paleta: --vital-vital (#ff6b35) como primary, --vital-balance (#2dd4bf) como secondary/accent. Remover variables confuses como --ebru-orange #8da399.
  4. Añadir detalles de profundidad: Texturas sutlegras (10% opacity), shadows capas (0 10px 30px en elementos primarios), borders de 3px con color vital en states hover.
  5. Evitar patterns SaaS: Grids genéricos centrados, gradients púrpura‑azul, cards idénticas sin variación, CTAs predecibles.
  6. Producción‑grade: Todas las states (hover, focus-visible, active) deben tener estilos consistentes; el código debe ser limpio, sin placeholders, listo para run.
