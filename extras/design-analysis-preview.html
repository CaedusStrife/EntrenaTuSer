Evaluación de Opciones Visuales

Análisis estructurado de las tres direcciones de diseño para Entrena Tu Ser, siguiendo el framework impeccable y las directrices del PRODUCT.md.

BOLDER Persuade

Mejor para

  • Screens de marketing y onboarding
  • Highlight key features
  • Landing pages y campañas

Dirección Visual

  • Paleta de colores ampliada: naranja #ff6b35 dominante
  • Gradients complementarios y blooms
  • Motion trails y pigment drops animados
  • Botones prominentes con shadows y hover

Puntos Fuertes

  • Dimensiones móviles reales (375px × 812px)
  • Jerarquía visual clara con Playfair Display
  • Tarjetas con interacción hover (translateY)
  • Gradientes sutiles en status-bar y nav-bar
  • Botonera primaria sólida con box-shadow
  • Grid de 2 columnas para métricas balanceado
Riesgo: Overstimulating para algunos users. Mitigación: "Reduced motion" toggle funcional, animations optional.
QUIETER Operate

Mejor para

  • Training workspace y dashboards
  • Meditation/cool-down screens
  • App UI operativa

Dirección Visual

  • Saturación reducida: naranja y teal muted
  • Whitespace expandido y gutters grandes
  • Textura de papel sutil o backgrounds clean
  • Chrome minimal y shadows reducidos

Puntos Fuertes

  • Teal #00c8b3 mantiene asociación calmante
  • Layout structure (sidebar + main content)
  • Avatar 3D integration (aún visible pero menos dominante)
  • Dark mode con ajustes de contraste apropiados
  • Fundamentals de accesibility (ARIA labels, focus visible)
Riesgo: Losing brand energy, feeling "empty". Mitigación: Small orange accent (10% opacity), paper grain texture.
DISTILL Read

Mejor para

  • Help docs y tutorial flows
  • Minimal dashboard view
  • Superficies de documentación

Dirección Visual

  • Elementos esenciales solamente
  • Fundación monocromática con color estratégico
  • Typography-first: jerarquía por tipografía y spacing
  • Zero decorative data: sin gradients, textures, shadows

Puntos Fuertes

  • Color mapping semantic (orange = action, teal = success)
  • Grid-based layout system (mantener columnas)
  • Accessibility breakpoints y text size toggles
  • Form component patterns (inputs, selects, buttons)
  • Skip-link y patterns de navegación por teclado
  • Adaptaciones mobile-responsive
Riesgo: Too corporate/clinical, losing brand voice. Mitigación: One subtle touch (1% paper texture, rounded corners).

1. Modo de la Superficie

Persuade — es una página de vista previa/landing que busca convencer al visitante del valor del producto. El objetivo es ganar atención y acción.

2. Contexto del Producto (desde PRODUCT.md)

Rubro Del PRODUCT.md Del Diseño
Nombre de marca "Entrena tu ser"; ícono activity de Lucide No hay ícono Lucide visible; texto "Entrena tu ser" en h1
Paleta de marca Naranja #ff6b35 (primaria/acción), Teal #00c8b3 / #009688 (secundaria/éxito) --pigment-orange: #8da399 (verde oliva apagado), --pigment-teal: #a67c52 (Sienna terroso)
Tipografía Sistema: Segoe UI, system-ui, -apple-system, sans-serif 'Outfit', sans-serif para cuerpo + 'Playfair Display', serif para títulos
Iconografía Lucide (outline, 24px base) Nav-items como rectángulos redondeados; ningún ícono Lucide visible
Tono visual Limpio, funcional, acentos cálidos (naranja) Tono "tierra": verdes oliva, sienna, ámbar claro
Restricciones Sin build step; ES modules no usados; CDN para librerías HTML/CSS/JS vanilla — compatible. Usa display: flex, grid, transiciones CSS

3. Puntos Fuertes del Diseño

  • Dimensiones móviles reales: 375 px × 812 px (formato iPhone)
  • Jerarquía visual clara: h1 en Playfair Display atrae la mirada
  • Tarjetas con interacción: box-shadow, border-radius, transition transform y hover
  • Gradientes sutiles en status-bar y nav-bar: vida sin recargar
  • Botonera primaria sólida: .btn-primary con box-shadow, border-radius gigante
  • Grid de 2 columnas para métricas: grid-template-columns: 1fr 1fr + gap: 15px

4. Áreas de Mejora (alineación con PRODUCT.md)

Área Problema Referencia Recomendación
Paleta de colores --pigment-orange: #8da399 está etiquetado como naranja pero es verde oliva apagado PRODUCT.md line 77: "Paleta actual: Naranja #ff6b35 (primaria/acción)" Reemplazar el verde oliva por naranja cálido consistente, o renombrar variables
Tipografía Se usan Outfit y Playfair Display; la marca compromete sistema genérico sin fuente propia PRODUCT.md line 78: "Tipografía: Sistema (Segoe UI, system-ui, -apple-system, sans-serif)" Si se quiere mantener Playfair Display para títulos, usarlo como override controlado; cambiar a Noto Sans o Source Sans 3
Iconografía No se usan íconos Lucide; los nav-items son rectángulos sólidos/vasos PRODUCT.md line 79: "Iconografía: Lucide (outline, 24px base)" Incorporar los 4 íconos de Lucide (home, play, heart, profile) alinear con compromiso de marca
Contraste y accesibilidad Texto h1 en #8da399 sobre #fcfaf7 tiene contraste AA (~4.5:1) justo PRODUCT.md line 100: "Estándar objetivo: WCAG 2.1 AA" Asegurar contraste AAA para texto normal y añadir outline visible en .btn-primary cuando tiene focus
Modo oscuro CSS usa --paper: #fcfaf7 (claro) y --paper-dark: #2d302d (definido pero no usado) PRODUCT.md line 77: "Modo oscuro: slate #0f172a / #1e293b" Implementar interruptor tema que cambie la variable --paper y ajuste los colores pigment-*
Componente avatar-placeholder Texto "Avatar 3D Zen" centrado sobre background var(--water) con borde punteado naranja PRODUCT.md line 26: "Avatar 3D personalizable que evoluciona con el progreso" Considerar animar el placeholder o usar una silueta que sugiere movimiento (líneas diagonales)

5. Comandos Sugeridos (según impeccable)

polish

Pasar a limpieza final: corregir colores, tipografía, contraste y asegurar hover/estado-focus impecable.

harden

Verificar errores de i18n (todo en español), edge cases (reduced motion, high contrast toggle), y que el CSS no rompa en navegadores antiguos.

adapt

Confirmar que el layout se mantiene en otros tamaños (SEF, tablet, desktop) sin romper grid ni lectura del h1.

colorize

Si se quiere mantener paleta tierra, agregar toques de naranja #ff6b35 y teal #00c8b3 como acentos estratégicos (bordes, focus, indicadores).

clarify

Revisar copy: "Entrena tu ser" está bien, pero los labels "Nivel", "Racha", "Próxima Sesión" podrían ser más explícitos según flujo de onboarding.

6. Veredicto

Fortalezas: El diseño es producción grade y cumple su propósito de persuasión en modo Persuave. Dimensiones móviles reales, jerarquía visual clara, tarjetas con interacción, gradientes sutiles, button primaria sólida, grid balanceado.
Ajustes necesarios: 1) Paleta de colores — la variable --pigment-orange no coincide con el compromiso de marca de naranja primario; conviene alinearla o renombrarla. 2) Tipografía -- Playfair Display otorga aire premium pero rompe simplicidad del sistema de la marca; decidir si se mantiene como styling ponctual o sustituir por fuente del sistema. 3) Iconografía -- ausente Lucide; su incorporación fortalecería coherencia de marca.

Una vez resueltos estos tres puntos (o se decide hacer un redesign que reemplace DESIGN.md), el diseño estaría listo para ser documentado y pasaría al comando polish para el acabado final.
