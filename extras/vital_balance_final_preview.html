Opción 1: Bolder

Energético & Alta Energía

BOLDER Persuade

Mejor para

  • Screens de marketing y onboarding
  • Highlight key features
  • Landing pages y campañas

Dirección Visual

  • Paleta de colores ampliada: naranja #ff6b35 dominante
  • Gradients complementarios y blooms
  • Motion trails y pigment drops animados
  • Botones prominentes con shadows y hover
Se mantiene: Brand commitments, features de accesibilidad, información architecture, Lucide iconography, system font stack
Riesgo: Overstimulating para algunos users. Mitigación: "Reduced motion" toggle funcional, animations optional.
QUIETER Cálmado

Mejor para

  • Training workspace y dashboards
  • Meditation/cool-down screens
  • App UI operativa

Dirección Visual

  • Saturación reducida: naranja y teal muted
  • Whitespace expandido y gutters grandes
  • Textura de papel sutil o backgrounds clean
  • Chrome minimal y shadows reducidos
Se mantiene: Teal #00c8b3, layout structure, Avatar 3D, dark mode, accessibility fundamentals
Riesgo: Losing brand energy, feeling "empty". Mitigación: Small orange accent (10% opacity), paper grain texture.
DISTILL Esencial

Mejor para

  • Help docs y tutorial flows
  • Minimal dashboard view
  • Superficies de documentación

Dirección Visual

  • Elementos esenciales solamente
  • Fundación monocromática con color estratégico
  • Typography-first: jerarquía por tipografía y spacing
  • Zero decorative data: sin gradients, textures, shadows
Se mantiene: Color mapping semantic, grid layout, accessibility breakpoints, form patterns, skip-link, mobile adaptations
Riesgo: Too corporate/clinical, losing brand voice. Mitigación: One subtle touch (1% paper texture, rounded corners).

Recomendación Oficial

Para app fitness donde usersspend 15-45 minutes per session, la Opción 2 (Quieter) strike the best balance—mantiene suficiente energía de marca mientras reduce visual noise para que users can focus on their training. El orange accent remains strong enough for motivation, pero el diseño breathes more.

Sugerencia: Empezar con Quieter como diseño por defecto, luego aplicar Bolder a onboarding/marketing, y Distill para ayuda/documentation.
